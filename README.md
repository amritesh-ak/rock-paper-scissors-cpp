# 🎮 Rock Paper Scissors (C++)

My first C++ mini project.

## Features

- Play Rock Paper Scissors against the computer
- Random computer choice
- Multiple rounds
- Simple console interface

## Technologies

- C++
- Standard Library

## How to Run

Compile:

```bash
g++ rock-paper-scissors.cpp -o game
```

Run:

```bash
./game
```
